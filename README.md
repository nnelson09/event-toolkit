# Event Toolkit

Aplicación web para gestionar eventos, cuentas regresivas y herramientas relacionadas.

## Características

- Inicio de sesión mediante Firebase Authentication.
- Sincronización en tiempo real con Firebase Realtime Database.
- Creación de eventos por duración.
- Creación de eventos por fecha y hora objetivo.
- Ajuste del tiempo restante de un evento.
- Eliminación de eventos.
- Actualización automática en tiempo real.

## Tecnologías

- HTML
- CSS
- JavaScript (ES6)
- Firebase Authentication
- Firebase Realtime Database
